Informationen zu Schichttypen

category Was sind Schichttypen?

Schichttypen definieren die Rahmenbedingungen für einzelne Schichten, z.B. Früh-, Spät- oder Nachtschicht. Sie legen Start-/Endzeit, Pausen, Farbe und weitere Eigenschaften fest.

add Schichttyp anlegen

Mit "Neuer Schichttyp" können Sie einen neuen Typ für Ihre Abteilung anlegen. Sie können die Eigenschaften jederzeit bearbeiten.

edit Bearbeiten & Aktionen

  • Bearbeiten: Öffnet den Dialog zur Bearbeitung des Schichttyps
  • Löschen: Entfernt den Schichttyp (nur wenn er nicht verwendet wird)
  • Detailansicht: Ein Klick auf eine Zeile öffnet die Detailansicht

info Besonderheiten

  • Farbe: Jede Schichtart kann farblich hervorgehoben werden
  • Nachtarbeit: Nachtstunden werden automatisch berechnet
  • Pausen: Pausenzeit kann individuell pro Schichttyp festgelegt werden
