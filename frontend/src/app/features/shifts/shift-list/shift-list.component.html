Informationen zur Schichtplan-Seite

calendar_today Wochenansicht

Der Schichtplan wird in Wochenansicht angezeigt. Navigieren Sie mit den Pfeiltasten zwischen den Wochen oder springen Sie mit dem "Heute"-Button zur aktuellen Woche.

drag_indicator Drag & Drop

Ziehen Sie Mitarbeiter aus der Liste auf die gewünschten Schicht-Zellen, um Schichten zuzuweisen. Konflikte werden automatisch erkannt und rot markiert.

warning Besonderheiten

  • Konflikterkennung: Überschneidungen mit anderen Schichten oder Abwesenheiten werden automatisch erkannt
  • Unterbesetzung: Gelbe Markierungen zeigen an, wenn die Mindestanzahl an Mitarbeitern nicht erreicht wird
  • Qualifikationen: Das System prüft, ob Mitarbeiter die erforderlichen Qualifikationen haben
  • Veröffentlichung: Schichtpläne können als Entwurf gespeichert oder veröffentlicht werden

picture_as_pdf Export

Exportieren Sie den Schichtplan als PDF über den Button unten rechts.
