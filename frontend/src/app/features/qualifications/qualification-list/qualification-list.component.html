Informationen zu Qualifikationen

school Was sind Qualifikationen?

Qualifikationen beschreiben besondere Fähigkeiten, Zertifikate oder Berechtigungen, die für bestimmte Schichten oder Aufgaben erforderlich sind.

add Qualifikation anlegen

Mit "Neue Qualifikation" können Sie eine Qualifikation für Ihre Abteilung anlegen. Sie können Name, Beschreibung und Abteilung festlegen.

edit Bearbeiten & Aktionen

  • Bearbeiten: Öffnet den Dialog zur Bearbeitung der Qualifikation
  • Löschen: Entfernt die Qualifikation (nur wenn sie nicht verwendet wird)
  • Detailansicht: Ein Klick auf eine Zeile öffnet die Detailansicht

info Besonderheiten

  • Abteilungsfilter: Qualifikationen können abteilungsspezifisch verwaltet werden
  • Verknüpfung: Qualifikationen werden Schichttypen und Mitarbeitern zugeordnet
  • Pflichtqualifikationen: Für bestimmte Schichten können Pflichtqualifikationen definiert werden
