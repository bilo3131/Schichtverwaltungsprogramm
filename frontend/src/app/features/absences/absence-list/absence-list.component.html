Informationen zu Abwesenheiten

event_available Was sind Abwesenheiten?

Abwesenheiten umfassen alle Zeiträume, in denen Mitarbeiter nicht arbeiten, z.B. Krankheit, Urlaub, KUG oder Sonstiges.

add Abwesenheit anlegen

Mit "Neue Abwesenheit" können Sie eine Abwesenheit für einen Mitarbeiter erfassen. Typ, Zeitraum und Notizen können angegeben werden.

edit Bearbeiten & Aktionen

  • Bearbeiten: Öffnet den Dialog zur Bearbeitung der Abwesenheit
  • Löschen: Entfernt die Abwesenheit (nur mit entsprechender Berechtigung)
  • Detailansicht: Ein Klick auf eine Zeile öffnet die Kalenderansicht

info Besonderheiten

  • Typen: Verschiedene Abwesenheitstypen werden farblich hervorgehoben
  • Filter: Abwesenheiten können nach Typ und Zeitraum gefiltert werden
  • Verknüpfung: Urlaubsanträge werden über die Urlaubsverwaltung verwaltet
