Informationen zur Personalverwaltung

group Mitarbeiterübersicht

Hier sehen Sie alle Mitarbeiter Ihrer Organisation. Sie können nach Beschäftigungsart und Status filtern.

add Mitarbeiter anlegen

Mit dem Button "Neuer Mitarbeiter" können Sie neue Mitarbeiter hinzufügen. Die Berechtigungen richten sich nach Ihrer Rolle.

edit Bearbeiten & Aktionen

  • Bearbeiten: Öffnet den Dialog zur Bearbeitung der Mitarbeiterdaten
  • Passwort zurücksetzen: Setzt das Passwort des Mitarbeiters zurück
  • Löschen: Entfernt den Mitarbeiter aus dem System (nur mit entsprechender Berechtigung)

info Besonderheiten

  • Rollen: Die Rolle eines Mitarbeiters bestimmt die Zugriffsrechte im System
  • Status: Aktiv/Inaktiv zeigt, ob ein Mitarbeiter aktuell beschäftigt ist
  • Detailansicht: Ein Klick auf eine Zeile öffnet die Detailansicht
