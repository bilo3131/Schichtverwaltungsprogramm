Informationen zum Kalender

event Was zeigt der Kalender?

Der Kalender bietet eine Übersicht über alle Termine, Meetings, Schulungen, Projekte und Firmenevents. Feiertage werden farblich hervorgehoben.

add Termin anlegen

Klicken Sie auf einen Tag oder nutzen Sie den Button "Neuer Termin", um einen neuen Kalendereintrag zu erstellen.

edit Bearbeiten & Aktionen

  • Bearbeiten: Öffnet den Dialog zur Bearbeitung eines Termins
  • Löschen: Entfernt den Termin aus dem Kalender
  • Drag & Drop: Termine können per Drag & Drop verschoben werden

info Besonderheiten

  • Legende: Farben und Kategorien werden in der Legende erklärt
  • Filter: Termine können nach Abteilung oder Typ gefiltert werden
  • Detailansicht: Ein Klick auf einen Termin öffnet die Detailansicht
